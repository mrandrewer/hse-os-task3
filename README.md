# Домашнее задание 3

Дисциплина: Архитектура ВС и операционные системы
Тема: Файловые системы
Форма проверки: самопроверка
Имя преподавателя: Алексей Федин
Время выполнения: 2 академических часа

Цель задания:
Научиться использовать Docker для работы с контейнерами

## Задание

1. Установите Docker на свой компьютер. Обратите внимание на особенности установки в разных операционных системах.
1. Создайте Dockerfile для простого веб-приложения.
1. Соберите образ Docker из Dockerfile.
1. Запустите контейнер из созданного образа и проверьте его работоспособность в браузере.

Опционально:

1. Измените веб-приложение в Dockerfile (например, поменяйте порт) и пересоберите образ.
1. Ознакомьтесь с командой Docker Compose для управления множеством контейнеров и создайте простой файл docker-compose.yml для запуска нескольких контейнеров одновременно.

## Чек-лист самопроверки

- Docker установлен и работает.
- Dockerfile создан.
- Образ собирается.
- Контейнер запускается.
- В ответе на задание указана ссылка на Dockerfile, доступ к файлу открыт.
